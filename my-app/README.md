# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## TFLite + YOLO setup (iOS)

The **ios/** folder is generated by `expo prebuild`. A config plugin injects the **YOLO frame processor plugin** (fast native inference) at prebuild time.

1. Install dependencies

   ```bash
   npm install
   ```

2. Generate the iOS project (includes the YOLO plugin)

   ```bash
   npx expo prebuild --platform ios
   ```

3. Install pods

   ```bash
   cd ios
   pod install
   cd ..
   ```

4. Add the model to the iOS bundle

   Put `ball_detection.mlpackage` in `ios/`, then in Xcode: open `ios/myapp.xcworkspace` → target **myapp** → **Build Phases** → **Copy Bundle Resources** → add `ball_detection.mlpackage`. For TFLite fallback you can add `newer_best_int8.tflite` the same way.

5. Build the dev client

   ```bash
   npx expo run:ios
   ```

6. Start Metro

   ```bash
   npx expo start --dev-client -c
   ```

## Using the app

- **Test tab**: run inference on `test.jpg`, `test2.jpg`, `test3.jpg`, `test4.jpg`.

## iOS signing help (physical device)

If you get signing errors:
1. Open `ios/myapp.xcworkspace` in Xcode
2. **Signing & Capabilities** → enable **Automatically manage signing**
3. Select your **Team**

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).
